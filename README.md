# Movie-&-Songs-Report

Interactive **Movie & Songs Report Dashboard** built in **Power BI** to analyze movie songs, language distribution, artist records, and emotion-based music insights using data visualization and reporting techniques.

---

## Project Overview

This dashboard helps track:

- Total Artists
- Total Records
- Available Languages
- Emotion Categories
- Movie-wise Song Distribution
- Language-wise Analysis
- Emotion Distribution by Language
- Average Songs per Movie

---

## Tools Used

- Power BI
- Data Visualization
- DAX Measures
- Charts & Graphs
- Dashboard Design

---

## Key Insights

- Telugu songs dominate the dataset compared to other languages.
- Love and Joy are the most common emotion categories.
- Emotion distribution varies across different languages.
- Some movies contain significantly higher song counts than others.
